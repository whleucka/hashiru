# v1.12.0

Installer release. The ISO asks its questions as steps, erases nothing until
you have reviewed them, and a non-US keyboard now reaches the desktop.

## ISO

- An animated splash, then one page per step: Keyboard, Network, Account,
  Machine, Disk, Review.
- Keyboard comes first and applies at once, so passwords are typed on it.
  Hyprland gets the matching layout in `~/.config/hashiru/hypr/local.lua`;
  before, every install had a `us` desktop.
- Timezone pre-filled from a geo-IP lookup (UTC if it fails), then picked
  from a list, as is the language. The Toronto default is gone.
- Disks come from a list without the installer's own USB stick; one too small
  is refused when picked.
- A review card shows every answer, any step can be redone, and the disk is
  erased only after you type its name.
- `stage0.sh --dry-run` walks every step and prints the config, secrets
  redacted.
- `iso/build.sh` refuses an unpushed commit, whose installs would fail at the
  clone.

## Installer look

- One banner and the Tokyo Night palette on the ISO, first boot and
  `install.sh`, from `lib/ui.sh`, including on a bare console.
- gum draws the prompts when it can, plain `read` otherwise. It ships on the
  ISO, the base install and `terminal.txt`.
- `install.sh` stops emitting escape codes into pipes.

## Also

- Stage 15 drops the GRUB boot tune, which never played.
- `rm`, `cp`, `mv` and `ln` are no longer aliased to `-i`, which stalled
  tools on a hidden prompt.
- GPG prompts work on the desktop: `pinentry` and `gcr` are installed and
  `GPG_TTY` survives zsh's instant prompt.
- Clamshell remembers the panel's own mode instead of one laptop's.
- `dev.txt` installs the ISO build and test tools; `iso/test-qemu.sh` names
  anything missing.

## Upgrading

`hashiru update`, then open a new shell for the alias change. The new
installer is on this release's ISO.
