# v1.11.0

Security release. `hashiru update` only takes commits signed by a known key,
the screen actually locks, and tty1 autologin needs an encrypted root.

## Update

- `hashiru update` fetches, checks the upstream tip's signature against
  `keys/hashiru.asc`, and only then fast-forwards. Before, anyone able to push
  to main could run root on every Hashiru machine.
- The key file is read from the commit already checked out, never the incoming
  one, so a push can't vouch for itself.
- A refusal prints how to inspect the commits and how to take them anyway.
- GitHub web merges are signed by GitHub, not this key, and are refused.
- `/etc/hashiru-release` is parsed, not sourced. A tag name holding `$(...)`
  ran as the user on the next `hashiru status` or `doctor.sh`.

## Lock screen

- Nothing locked before: there was no hypridle config, and hypridle was
  stopped on AC. A closed lid resumed straight to the desktop.
- Idle locks after 5 min on battery, 15 min on AC; the screen goes off 30 s
  later. Every sleep locks first.
- tty1 autologin is set up only when `/` is on LUKS, where the disk
  passphrase is the login. On a plain disk, stage 30 removes it.

## Hardening

- kitty's socket and the weather caches live in `$XDG_RUNTIME_DIR`, not `/tmp`.
- Weather fetches wttr.in over https and escapes the reply before waybar
  renders it. The tooltip shows pressure, not precipitation.
- The installer writes its creds file and Wi-Fi keyfile 600 from the start,
  and `/var/log/archinstall` is root-only.
- `bd` images are 600 and owned by you, `usb` validates its bus-port id,
  `write-usb` refuses a mounted device and asks for `yes`, `what` uses https.

## Upgrading

`hashiru update`. Coming from v1.10.1 or older, this one pull is unverified
(the key file isn't there yet) and warns; every update after it is checked.
Then log out and back in so hypridle picks up its config, and restart kitty.

Without LUKS you now log in on tty1 by hand after boot. Existing installs
can also run `sudo chmod -R go-rwx /var/log/archinstall`.
