# v1.9.0

Minor release. Two new CLI commands, an update that stops caring about untracked
files, and tmux's layout presets in herdr.

## Commands

- `hashiru version` — one line from `/etc/hashiru-release`, which says when the
  checkout is ahead of what the machine has replayed.
- `hashiru config` (also `edit`) opens this machine's `hashiru.conf` in
  `$VISUAL`/`$EDITOR`, seeding it from the example the first time.
- `hashiru log --last` pages only the most recent run.
- `hashiru status` gains a `checkout:` line, and bounds its fetch to 10s so a
  half-up network can't hang it.
- `hashiru install --list` names every stage.

## Updates

- Only changes to *tracked* files block an update. Untracked ones are counted
  and left alone — refusing over one made a `.gitignore` entry the price of
  every runtime file a stowed program writes.
- `install.sh` stamps `/etc/hashiru-release` now, before the reboot prompt.
  `hashiru update` used to stamp afterwards, racing a reboot already enqueued.
- The warnings digest is written only during an install run, so a CLI error no
  longer surfaces from `hashiru report`; the log rotates past 5 MiB.
- `HASHIRU_ASSUME_YES` and `HASHIRU_NO_REBOOT` join `HASHIRU_NO_REFLECTOR` as
  `hashiru.conf` knobs — a pair worth setting on a box you only reach over ssh.
  Flags raise them, never lower them; `HASHIRU_NO_REBOOT=0 hashiru update` drops
  one for a run. `hashiru.conf.example` trimmed to match.

## Desktop

- `herdr-relayout` replaces `herdr-flip` on `ctrl+shift+o`: columns, rows,
  main-vertical, main-horizontal, grid, skipping presets identical at the
  current pane count. Panes are re-parented, so ptys survive.
- A ZOOM badge at the right edge of herdr's tab bar.
- `~/.config/herdr` is stowed `--no-folding`, so herdr's logs, session state and
  sockets stop landing in the checkout — see [`internals.md`](../internals.md).
- waybar's clock opens Google Calendar; the weather module resolves the forecast
  for wherever the machine is, rather than hardcoded coordinates.
  `~/.config/hashiru/waybar/weather.conf` pins a provider.
- kitty: font size 12, background opacity 0.8.

## Removed

- calcurse, `calcurse-sync`, `cronie`, and the two Python modules its caldav
  sync needed.

## Upgrading

`hashiru update`. Stage 45 will not unfold `~/.config/herdr` underneath a
running herdr — it warns and defers. Stop herdr, then `hashiru update 45`.
