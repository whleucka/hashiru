# v1.16.0

Machines with an Nvidia card now get Nvidia's driver automatically, and a
few herdr binds and shell glitches are fixed.

## Nvidia

- Stage 30 detects the card. Turing or newer (GTX 16xx, RTX) gets
  `nvidia-open`, `nvidia-utils` and `lib32-nvidia-utils`.
- `nvidia_drm` modesetting is turned on, and the `kms` hook comes out of
  `mkinitcpio.conf` so nouveau leaves the initramfs.
- Older cards stay on nouveau with a warning, since `nvidia-open` doesn't
  support them. Machines without an Nvidia card are untouched.
- `hashiru doctor` gains an Nvidia section on machines with a card.
- Not yet tested on real Nvidia hardware, including laptops that pair one
  with integrated graphics.

## herdr

- Tabs: ALT+TAB for previous, ALT+SHIFT+TAB for next (were ALT+[ / ALT+]).
- Agents: CTRL+SHIFT+P for previous, CTRL+SHIFT+N for next (were
  CTRL+SHIFT+< / CTRL+SHIFT+>).
- Quick jump moves to prefix+P (was CTRL+SHIFT+P).

## Shell

- CTRL+L no longer types `;5;108~` after a TUI dies without restoring the
  terminal's key mode. The mode is reset at every prompt.
- The reset doesn't trigger Powerlevel10k's instant prompt warning on new
  terminals.

## Upgrading

`hashiru update`. On a machine with a supported Nvidia card, reboot afterwards
to load the driver. Stage 45 restows the herdr binds and `.zshrc`.
