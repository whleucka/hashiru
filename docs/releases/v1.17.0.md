# v1.17.0

The system menu opens from waybar's Arch logo, hashiru-tui gains a News area,
and DNS survives a VPN going down.

## System menu

- Click waybar's Arch logo to open the system menu, as SUPER+ALT+Space does.
- A second press, or click, focuses the open menu instead of stacking another.
- hashiru-tui v0.5.0: a News area.

## Binds

- Group tabs: ALT+H / ALT+L for previous / next, ALT+SHIFT+H / ALT+SHIFT+L to
  move the active tab (were CTRL+SHIFT+H/L and CTRL+SHIFT+ALT+H/L).
- CTRL+Print screenshots the focused window.
- herdr: tabs on CTRL+SHIFT+H / CTRL+SHIFT+L (were ALT+TAB / ALT+SHIFT+TAB),
  agents on CTRL+[ / CTRL+] (were CTRL+SHIFT+P/N), new workspace on
  CTRL+SHIFT+N (was prefix+SHIFT+N).

## Fixes

- DNS no longer disappears when a VPN (wg-quick, openvpn) goes down.
  NetworkManager now hands its servers to openresolv, so they come back the
  moment the VPN's are removed.
- Stage 15 no longer fails when grub-btrfsd regenerates the snapshot menu at
  the same time. It waits for the daemon, and retries once.
- GTK4/libadwaita apps (gnome-calculator and the like) are dark too.
- Waybar's clock follows the zone picked at install. It was pinned to one
  zone to dodge a libstdc++ bug that has since been fixed.
- `hashiru doctor` no longer flags Chromium's lock files as broken links on a
  machine named `hashiru`.
- The group lock bind uses Hyprland's current dispatcher.
- kitty is a little more transparent (0.825, was 0.9).

## Upgrading

`hashiru update`. Stage 10 installs the NetworkManager DNS config and reloads
NetworkManager without dropping the connection. Stage 99 rebuilds hashiru-tui.
Restart waybar, or log out and back in, to pick up the clock and the logo.
