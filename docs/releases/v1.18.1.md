# v1.18.1

kitty's home session exists on every machine.

## Fixes

- kitty.conf starts every kitty in `~/.config/hashiru/kitty/sessions/home.kitty-session`,
  but nothing created that file, so on a fresh machine kitty's first tab sat
  outside any session. Stage 45 now writes a minimal one: one tab, a shell in
  `~`. It is created once and never overwritten; CTRL+SHIFT+W saves your own
  layout into it.

## Upgrading

`hashiru update`, then restart kitty. A machine that already has the file
keeps it.
