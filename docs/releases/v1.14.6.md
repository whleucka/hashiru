# v1.14.6

`update-system` is gone.

## Removed

- `update-system`, and the `wow.mp3` it played when an update finished.
  SUPER+SHIFT+U runs the system menu's update since v1.14.5, so nothing
  called it. In a terminal, `hashiru update` is the update.

## Upgrading

`hashiru update`. Stage 45 restows the bin package, which removes the
`~/.local/bin/update-system` link.
