# v1.6.0 — Overrides

Machine-local config moves out of the repo, so it survives `hashiru update`.

## Overrides

- `~/.config/hashiru/` is the override tree. Nothing in the install writes into
  it, so replay cannot clobber it.

| File | Effect |
|---|---|
| `hypr/<module>.lua` | replaces that module |
| `hypr/<module>.extra.lua` | runs after it |
| `hypr/local.lua` | runs last — override any `hyprland.lua` setting |
| `kitty/*.conf` | read after `kitty.conf` |
| `waybar/style.css` | cascades over the bar styling |

- Modules: `monitors`, `autostart`, `keybinds`, `windowrules`, `layerrules`,
  `clamshell`. A file that fails to parse is skipped, not propagated.
- `hashiru.conf` moves to `~/.config/hashiru/`; the old path is still read.
- `hashiru doctor` lists your overrides and syntax-checks the Lua.

## Changes

- **Monitors no longer ship a layout**, just the auto-detect catch-all. It used
  to hardcode `eDP-1`, which is the internal panel on every laptop. Real layouts
  moved to `examples/hypr/`.
- **chromium** from `[extra]` replaces `omarchy-chromium-bin`. Flags unchanged.
- New `docs/roadmap.md`.

## Upgrading

`hashiru update`. Put your monitor layout in place first — the repo no longer
carries one:

```bash
cp /opt/hashiru/examples/hypr/monitors.thinkpad-t14s.lua ~/.config/hashiru/hypr/monitors.lua
```
