# v1.14.3

The system menu's Overview shows the machine, and AUR builds stop
installing debug packages.

## The system menu

- hashiru-tui v0.4.2. **Overview** shows the machine as fastfetch would:
  model, kernel (its own row now), CPU, GPU, Hyprland, displays, swap,
  battery health and how many packages are installed. Not OS, shell or
  terminal: on Hashiru those are always Arch, zsh and kitty.
- An action run from the palette now shows its area. "Search the repos and
  the AUR" from Snapshots used to start a search in a Packages you couldn't
  see.

## Packages

- `httpie` and `shellcheck` in `dev.txt`.
- `mkinitcpio` in `base.txt`: archinstall puts it on every install, so it's
  listed as Hashiru's, not as one you added.
- No more `-debug` packages beside AUR ones (`yay-bin-debug`, ...): Arch's
  `makepkg.conf` builds them by default, and stage 10 now installs
  `/etc/makepkg.conf.d/99-hashiru.conf` with `OPTIONS+=(!debug)`.

## Upgrading

`hashiru update`. Stage 10 installs the makepkg drop-in and stage 99
rebuilds hashiru-tui at the new pin. Debug packages already installed stay;
`pacman -Qq | grep -- '-debug$'` lists them, `sudo pacman -Rns` removes
them.
