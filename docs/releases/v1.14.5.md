# v1.14.5

SUPER+SHIFT+U opens the system menu's update.

## The system menu

- SUPER+SHIFT+U runs `hashiru-tui --run updates.update` in a floating
  window: the same update as `u` in Updates (`hashiru update --no-reboot
  --no-reflector`), and the menu is there when it ends. `update-system`
  is still on your PATH; it just isn't bound any more.
- hashiru-tui v0.4.4. An action started with `--run` waits for the
  terminal to answer Bubble Tea's startup queries, so the update no longer
  opens with `^[[?2026;2$y^[[?2027;0$y` printed above it.

## Upgrading

`hashiru update`. Stage 45 restows the keybind and stage 99 rebuilds
hashiru-tui at the new pin.
