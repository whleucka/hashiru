# v1.10.1

Patch release.

## Security

- kitty remote control is `socket-only`. `yes` also obeyed escape codes written
  to the tty, so anything that printed could `launch` or `send-text` locally.
  `ssh.conf` and its `forward_remote_control` are gone for the same reason.

## Upgrading

`hashiru update`, then restart kitty: open windows keep the old setting. A
`~/.config/hashiru/kitty/*.conf` that sets `allow_remote_control` still wins.
