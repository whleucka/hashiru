# v1.10.0

Minor release. The reference moved to the website, PHP stopped missing its
drivers, and `super+hjkl` reaches panes on another machine.

## Docs

- `keybinds.md`, `internals.md` and `roadmap.md` left the repo for
  [the site](https://hashiru.williamhleucka.com). Every pointer that named them —
  `lib/common.sh`, stage 45, `keybinds.lua`, the README — now names a URL.
- `docs/releases/` and `iso/README.md` stay, because something reads them here.

## PHP

- `config/php/conf.d/99-hashiru.ini` enables `curl`, `zip`, `sqlite3`,
  `pdo_sqlite` and `iconv`. Arch ships `php.ini` with every `extension=` line
  commented, so `php-sqlite` landed its `.so` and nothing loaded it.
- A drop-in rather than an edit: `php.ini` belongs to pacman, which replaces it
  with a `.pacnew` and quietly reverts the change. Stage 99 re-comments any of
  the five already uncommented there, since loading one twice only warns.

## Desktop

- `super+hjkl` drives panes inside a *remote* herdr: `ssh` joined the nav list.
  Blunt by necessity — a plain remote shell gets the injection too and the key
  does nothing there. See
  [keybinds](https://hashiru.williamhleucka.com/docs/keybinds.html#focus).
- `herdr-route` stops at herdr's outer edge on a headless server rather than
  exec'ing a `hypr/scripts/focus` that is not there and eating the keypress.
- Group tabs are legible: the active groupbar tab takes the accent instead of the
  same translucent black as the inactive one.
- herdr's browser split is gone from `ctrl+shift+w`, which stays unbound so
  kitty's `close_window` cannot fire from muscle memory.
- kitty: font size 14, background opacity 0.85.
- `monitors.lua`'s examples suggest a description *prefix* and
  `mode = "preferred"`: a docked display advertises fewer modes than its spec
  sheet, and asking for one it lacks is a black screen.

## Shell

- `.zshrc` sources `~/.zshrc.local`. The override was documented and never wired.
- `upg` is `hashiru update --no-reboot`, falling back to `yay -Syu`. `upd` and `g`
  are gone, `gt` is `git tag`, and the `apt` branches went with them.

## Fixes

- Shellcheck findings in the `hashiru changelog` pager and stage 45.

## Upgrading

`hashiru update`. The PHP drop-in lands only where `php` is installed, and stage
99 warns once per line it comments.

If you typed `upg` for `yay -Syu`, it now runs a full replay.
