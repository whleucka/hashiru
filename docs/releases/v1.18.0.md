# v1.18.0

kitty replaces herdr as the multiplexer, every workspace can pick its own
layout, and ALT+Tab switches windows.

## kitty is the multiplexer

- herdr is gone: its stow package, stage 60, the SUPER+SHIFT+Return bind and
  its doctor checks. Tabs, splits and sessions are kitty's own now, on the
  chords herdr used:
  - tabs: CTRL+SHIFT+T new, CTRL+SHIFT+ALT+T rename, CTRL+SHIFT+Q close,
    CTRL+SHIFT+H / L previous / next, CTRL+1…9 jump
  - splits: CTRL+SHIFT+S below, CTRL+SHIFT+D beside, CTRL+SHIFT+X close,
    CTRL+SHIFT+M maximize, CTRL+SHIFT+J / K next / previous pane
  - sessions: CTRL+SHIFT+\ picks one, CTRL+SHIFT+N starts one,
    CTRL+SHIFT+W saves it. Session files live in
    `~/.config/hashiru/kitty/sessions/`; kitty starts in `home.kitty-session`
    there if it exists.
- Scrollback is 10,000 lines with a scrollbar, and pages in neovim
  (CTRL+SHIFT+G, or CTRL+SHIFT+/ to search). CTRL+SHIFT+Up / Down jump between
  prompts, CTRL+SHIFT+Y copies the last command's output.
- SUPER+H/J/K/L walks (n)vim splits, then kitty splits, then Hyprland windows.
  SUPER+CTRL+H/J/K/L resizes along the same chain.
- herdr itself is left installed if you have it. Stage 45 removes only the stale
  links Hashiru had placed in `~/.config/herdr`.

## Layouts

- SUPER+A picks the focused workspace's layout: d dwindle, s scrolling,
  m master, o monocle, c columns, g grid, p spiral. Any other key cancels.
- SUPER+O flips whatever the layout can: split direction, master orientation,
  column width, spiral rotation.
- Waybar shows the layout after the workspace buttons, dwm-style (`[]=`,
  `[M]`, `|||`…). Click for the next, right-click for the previous.
- In monocle, SUPER+J / K step through the stack.

## Binds

- ALT+Tab switches between every window, most recent first; SUPER+Tab keeps to
  this workspace. SHIFT goes backwards. (snappy-switcher, from the AUR.)
- SUPER+SHIFT+A opens Claude Code in a terminal.

## Fixes

- NTFS: ntfs-3g and ntfsprogs are installed, for the FUSE driver and ntfsfix.
- The layout picker's legend is readable on a rotated monitor.

## Upgrading

`hashiru update`. Stage 20 builds snappy-switcher; log out and back in to start
its daemon and pick up the waybar layout indicator. Restart kitty for sessions.
