# v1.14.4

Updating from the system menu skips the reboot and the mirror ranking.

## The system menu

- hashiru-tui v0.4.3. `u` in Updates (and "Update the system" in the
  palette) now runs `hashiru update --no-reboot --no-reflector`. The menu
  is still open when the run ends, so it no longer asks to reboot under
  you, and it skips the minute stage 10 spends ranking mirrors. Run
  `hashiru update` in a terminal for the full run.

## Desktop

- The launcher (fuzzel) is readable again: size 11, and `dpi-aware=no`
  so it no longer scales by the monitor's DPI.

## Upgrading

`hashiru update`. Stage 99 rebuilds hashiru-tui at the new pin.
