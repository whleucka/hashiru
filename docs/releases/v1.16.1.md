# v1.16.1

Fresh installs no longer stop at stage 10, and the installer's review shows
the WiFi name once.

## Fixes

- Stage 10 restarts `upower`, but the package only arrived with `waybar` in
  stage 30, so every fresh install since v1.15.0 failed with `Unit
  upower.service not found`. `upower` is now in `base.txt`.
- The installer's Review panel and log printed the SSID twice.

## Nvidia

- v1.16.0's driver detection now works on real hardware: a desktop GTX 1660.
  Laptops that pair a card with integrated graphics are still untested.

## Upgrading

`hashiru update`. Existing machines already have `upower`, so nothing changes
for them. The SSID fix is in this release's ISO.
