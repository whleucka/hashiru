# v1.7.3

Patch release. Clamshell docking gets rewritten, and the bind reference lands.

## Clamshell

- Lid state is read from `/proc/acpi/button/lid/LID/state`, never from the switch
  event — libinput synthesises a lid-open out of typing on this class of machine,
  which is what used to re-light the panel behind a shut lid.
- Undock-and-suspend waits out a modeset and decides from live state, so packing
  up no longer suspends into a black resume.
- Re-enabling the panel forces DPMS on, and falls back to reloading the layout
  via `hashiru.load("monitors")` when a rule is accepted but does nothing — the
  "lid open, no display" case, without discarding a machine-local layout.

## Keybinds

- `docs/keybinds.md` — the full bind reference, by group.
- `Shift+Print` saves a selected region to `~/Pictures/Screenshots`; `Print`
  still copies, `Super+Print` still grabs the whole screen.
- Personal site shortcuts moved out of the repo, into
  `~/.config/hashiru/hypr/keybinds.extra.lua`.

## Fixes

- `tree-sitter-cli` added to `dev.txt`; without the binary every `:TSInstall`
  failed with `ENOENT`.
- The `-h` global zsh alias is dropped — it ate the following argument, so
  `gh auth refresh -h github.com` never saw the host. `--help` keeps its pager.
- btop sets `save_config_on_exit = false`; quitting it was dirtying the checkout.
- `~/.claude/skills` is pre-created and stowed `--no-folding`, so skills written
  later stay out of the checkout. A `hashiru` skill ships there.
- `lint.yml` uses `actions/checkout@v7`.

## Docs

- README rewritten; `internals.md` gains the stage table and override surface;
  `roadmap.md` records what would earn a major, and why v2.0 didn't.

## Upgrading

`hashiru update`. All of it lands on restow except `tree-sitter-cli`, which
needs the package stage.
